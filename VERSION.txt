Logistics & Field Service System (LMI & NNAP)
=====================================================
Version: v1.8.3
Build Date: 2026-10-06
Target: GitHub Pages (doit-on.github.io/Logistic-service)

Key Features in v1.8.3:
1. Responsive & Compact UI (PC/Notebook & Mobile):
   - ปรับการแสดงผลหน้าจอแบบ 2-Column Grid (md:grid-cols-2) สวยงาม กระชับ ไม่ยืดยาว ลดช่องว่างสูญเปล่าบนจอ PC และโน้ตบุ๊ก
   - การ์ดใบงานและการ์ดค่าใช้จ่ายจัดสรรข้อมูลสมส่วน ปุ่มคำสั่งและข้อมูลไม่กระจายตัว
   - ใช้งานสัมผัสบนมือถือและสมาร์ตโฟนได้อย่างสะดวก รวดเร็ว และลื่นไหล
2. DS Expense Reimbursement Voucher System (ใบสรุปเอกสารค่าใช้จ่ายเพื่อทำเบิกกับระบบ DS):
   - สร้างใบสรุปขอเบิกค่าใช้จ่ายส่งระบบ DS พร้อมเลขอ้างอิงระบบ Logistics (Job Number เช่น LMI-JOB-202610-0001, Expense Number เช่น EXP-202610-0001)
   - สร้างรหัสอ้างอิงอัตโนมัติ (DS-REQ-YYYYMM-XXXX) พร้อมตัวอักษรภาษาไทยแสดงยอดเงินรวม (Baht Text เช่น แปดร้อยบาทถ้วน)
   - ช่องลงนามทางการ 3 ฝ่าย (1. ผู้ขอเบิกเงิน / 2. ผู้ตรวจสอบความถูกต้อง Admin / 3. ผู้อนุมัติจ่าย DS หรือ MD)
   - รองรับพิมพ์เอกสารขนาดมาตรฐาน A4 / บันทึกเป็น PDF
   - ปุ่มคัดลอกข้อความสรุปเพื่อนำไปกรอกหรือแนบในระบบ DS สะดวกทันใจ
   - ปุ่มส่งออกข้อมูลเป็นไฟล์ CSV สำหรับนำเข้าสู่ระบบ DS
   - แกลเลอรีรูปถ่ายสลิป/ใบเสร็จรับเงินในใบสรุป
